# Video ingestion. MediaPipe publishes wheels for CPython 3.9-3.12 ONLY, so on a
# newer interpreter these go in a separate environment:
#     Windows        py -3.12 -m venv .venv312
#                    .venv312\Scripts\pip install -r requirements-video.txt
#     macOS / Linux  python3.12 -m venv .venv312
#                    .venv312/bin/pip install -r requirements-video.txt
# On an interpreter MediaPipe supports, install requirements-video.txt into the
# same environment and skip the split entirely - `run.sh setup` does that.
#
# Everything else in this project works without them, because the pipeline
# consumes keypoints rather than pixels. One exception, worth knowing before you
# reach it: `runway_ai render` writes an annotated video and therefore needs
# OpenCV in *this* environment, not the MediaPipe one. It is not required here
# because most installs never render; add it when you want to:
#     python -m pip install opencv-python-headless
